# Drone Digital Twin – Flight, Environment & Health Monitoring

This project is a Python-based simulation of a Drone Digital Twin that models the behavior of a drone during flight under different environmental conditions.

The simulation monitors key drone parameters such as battery level, speed, GPS position, and altitude. It also simulates environmental factors including wind, weather conditions, and obstacles to observe their effects on drone performance.

The system includes basic health monitoring to detect conditions such as low battery, abnormal altitude, and GPS drift. The generated flight data is stored and visualized using Matplotlib to analyze the drone's movement and performance.

The project demonstrates the use of Python for simulation, robotics monitoring, data logging, anomaly detection, and visualization.

### Technologies Used

* Python
* Random
* Matplotlib

### Key Features

* Drone flight simulation
* Battery consumption monitoring
* Wind and weather simulation
* GPS path simulation
* Obstacle effects
* Altitude monitoring
* GPS drift detection
* Health alerts
* Flight data visualization

### Objective

To develop a simplified digital representation of a drone that can simulate flight conditions, monitor its health, and visualize its performance during operation.
